# hao-backprop-test

test project for backprop integration. Do not touch!

## Technology Stack

Python 3 / Flask — a minimal HTTP server that responds with `Hello, World!` to every request.

## Prerequisites

- Python 3.9 or higher

## Setup

1. (Optional) Create and activate a virtual environment:

   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the server:

   ```bash
   python app.py
   ```

The server starts at `http://127.0.0.1:3000/` and responds with `Hello, World!` (plain text, status 200) to all HTTP requests on all paths.
